프로그래머스 레벨 $ARGUMENTS 문제를 추천하고 풀이 환경을 세팅합니다.

다음 단계를 순서대로 실행해:

## 1. 문제 가져오기
아래 명령어를 실행해서 결과 JSON을 받아:
```bash
node /Users/lalalalz/IdeaProjects/algorithm-java/scripts/get_problems.js $ARGUMENTS
```

실행 중 stderr 출력은 진행 상황이니 무시하고, stdout의 JSON만 파싱해.

## 2. 파일 생성
JSON에서 `packageName`, `level`, `title`, `url`, `description` 을 추출해서:

- 디렉토리: `src/level{level}/{packageName}/`
- 파일: `src/level{level}/{packageName}/Solution.java`

Solution.java 형식 (description의 각 줄 앞에 ` * ` 붙이기):
```java
package level{level}.{packageName};

/**
 * 문제: {title}
 * URL: {url}
 *
 * === 문제 설명 ===
 *
 * {description - 각 줄 앞에 " * " prefix 추가}
 */
public class Solution {

    {javaMethod - 그대로 삽입, 들여쓰기 유지}

    public static void main(String[] args) {

    }
}
```

## 3. 완료 메시지 출력
```
✅ 문제 추천 완료!
제목: {title}
URL: {url}
파일: src/level{level}/{packageName}/Solution.java
```
