현재 작업 중인 Solution.java를 프로그래머스에 제출하고 채점 결과를 확인합니다.

다음 단계를 순서대로 실행해:

## 1. Solution.java 파일 결정

$ARGUMENTS가 있으면 해당 경로를 파일로 사용해.

$ARGUMENTS가 없으면 `src/` 디렉토리에서 가장 최근에 수정된 Solution.java를 찾아:
```bash
find /Users/lalalalz/IdeaProjects/algorithm-java/src -name "Solution.java" | xargs ls -t 2>/dev/null | head -1
```

## 2. 제출 실행

찾은 파일 경로로 아래 명령어를 실행해 (최대 3분 소요):
```bash
node /Users/lalalalz/IdeaProjects/algorithm-java/scripts/submit_solution.js <파일경로>
```

stderr 출력은 진행 상황으로 사용자에게 보여주고, stdout의 JSON을 파싱해서 결과를 출력해.

## 3. 결과 출력

JSON 필드:
- `result`: "pass" 또는 "fail"
- `score`: 점수 (0~100)
- `message`: 채점 결과 메시지

출력 형식:
```
채점 완료!
점수: {score}점
결과: {message}
```

score가 100이면 앞에 ✅, 아니면 ❌를 붙여줘.
